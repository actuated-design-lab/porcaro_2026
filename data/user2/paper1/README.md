# paper1/ — 論文投稿用テンプレート

使うときは、このフォルダを**コピーして** `<略称><年>`（例: `ral2027`）に名前を変え、下の表を埋める。
テンプレート（`paper1/`）自体は残しておく。

| 項目 | 内容 |
|---|---|
| 論文誌名 | （記入） |
| 投稿日 | （記入） |
| 投稿時のタグ | （記入。例: `ral2027-submit`） |
| 使ったタスクID・モデル | （記入。例: `Template-Porcaro-2026-ModelB-user2`） |
| 図表を作るスクリプト | （記入。どのスクリプトがどのファイルを読むか） |

## 中身

| フォルダ | 入れるもの |
|---|---|
| `eval/` | シミュレーション評価の生の出力（実験ごとにサブフォルダ） |
| `paper/` | 原稿の図表が読む集計済みの確定データ |
| `models/` | 実機に渡すモデル（ONNX など） |

不要なフォルダは消してよい。当てはまらないデータは目的が分かる名前のフォルダを作る。
