# data/user2/ — user2 のデータ

コード側は `source/porcaro_2026/porcaro_2026/tasks/direct/porcaro_2026/user2/`。

| フォルダ | 中身 |
|---|---|
| `conference1/` | 学会発表用のテンプレート（コピーして名前を変えて使う） |
| `paper1/` | 論文投稿用のテンプレート（コピーして名前を変えて使う） |

## ルール

- このフォルダには **user2 本人だけが書き込む。** 他の人は読むだけ。
- 論文・学会ごとに1フォルダ作る。名前は **`<略称><年>`**（例: `ral2026`, `jfps2026`, `robomech2027`, `si2026`）。
  修論用にまとめたいものは `thesis/` を作ってよい。
- 新しく始めるときは、テンプレートの `conference1/`（学会発表）か `paper1/`（論文投稿）を**コピーしてから名前を変える**。
  テンプレート自体は次の人のために残しておく。
- 中の構成は全フォルダ共通:
  - `eval/<実験名>/` … シミュレーション評価の生の出力（`simulation_log.csv` の木と manifest）
  - `paper/` … 原稿の図表が実際に読む、集計済みの確定データ。投稿後は書き換えない
  - `models/` … 実機（jetson_project）に渡す ONNX など
  - 上に当てはまらないものは目的が分かる名前のフォルダを作る（例: `replay/`）
- 別のフォルダのデータを使い回すときは、コピーせずパスで参照する。
- 投稿したら、そのときのコミットにタグを打つ（例: `git tag robomech2027-submit <commit>`）。
